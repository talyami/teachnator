# المولد الذكي للاختبارات 🧠✨
### Smart Quiz & Mnemonics Generator Web App

تطبيق ويب تفاعلي متكامل يحوّل الأوراق الدراسية، الكتب، ملفات الـ PDF ومستندات Word إلى تجربة تعليمية شيقة بنظام التلعيب (Gamification) ومفاتيح الحفظ السحرية (علم الذاكرة - Mnemonics)، مدعوماً بمراجعة أكاديمية مزدوجة من نماذج Google Gemini وموسيقى تركيز توليدية اصطناعية.

---

## 🌟 المميزات الرئيسية

1. **التحليل الذكي مزدوج الطبقات (Two-Tier LLM Pipeline):**
   - **الطبقة الأولى (المعلم المبتكر):** استخراج جميع الأسئلة وابتكار مفتاح حفظ سحري (Mnemonic) يربط السؤال بالإجابة بقصة طريفة أو تشابه صوتي.
   - **الطبقة الثانية (المفتش الأكاديمي):** تدقيق الأسئلة، مراجعة الإجابات المحلولة بدقة 100%، وتدارك أي سؤال ناقص.
   - **رسائل انتظار تفاعلية:** نصوص واضحة للمستخدم: `"الرجاء الانتظار، انا اقرأ المادة التعليمية وابتكر مفاتيح الحفظ السحرية..."` ثم `"الرجاء الانتظار، انا المفتش الصارم اراجع الاسئلة وادقق الاجابات 100%..."`.

2. **دعم الأسئلة المقالية القصيرة (Short Answer Questions) المبني على سياق المادة:**
   - **توليد ذكي ومضبوط بسياق الدرس (Context-Driven):** تقتصر أسئلة الإجابة القصيرة (`short_answer`) حصرياً على الأجزاء التي يقتضي سياق المادة والدرس صراحة كونها مقالية أو تعليلية (مثل: *علل، اذكر السبب، بم تفسر، ماذا يحدث عندما، أو التمارين المقالية المحددة في الدرس*)، في حين تصاغ الشروحات والمفاهيم والمعلومات العامة طبيعياً كأسئلة اختيار من متعدد (MCQ) أو صح/خطأ (Y/N).
   - **مصحح ذكي متسامح دلالياً (Semantic Inconsistency-Tolerant Evaluator):** يعتمد على نموذج الذكاء الاصطناعي لفحص المعنى العلمي المقصود وتجاوز الأخطاء الإملائية الشائعة (الهمزات، التاء المربوطة/الهاء، الياء والألف المقصورة)، التفاوت في الصياغة وتركيب الجمل، واختلاف المترادفات.
   - **تغذية راجعة أكاديمية دقيقة (AI Feedback & Revised Answer):** يقدم التطبيق للطالب نسبة التطابق الدلالي، تقييماً تفصيلياً يوضح مواطن الصواب أو النقص، الإجابة النموذجية المعتمدة مع نطقها صوتياً، وصياغة مقترحة سليمة.
   - **إدخال صوتي (Voice Dictation):** إمكانية إملاء الإجابة صوتياً باستخدام الميكروفون عبر Web Speech API.
   - **محرك تدقيق محلي احتياطي (Offline Fallback Engine):** محرك تطبيع عربي ومطابقة دلالية محلية يعمل حتى بدون توفر رصيد أو اتصال بالإنترنت.

3. **دعم Google Cloud Vertex AI والبحث الديناميكي الحي للنماذج:**
   - التبديل السلس بين **Google AI Studio** و **Google Cloud Vertex AI** (مع تحديد Project ID و Region و Bearer Token / API Key).
   - **بدون أي قوائم نماذج ثابتة مسبقاً:** يقوم التطبيق بالاستعلام الحي والمباشر من Google API لاكتشاف أحدث نماذج **Flash** و **Pro** وفرزها حسب أحدث الإصدارات فورياً.

4. **طريقة الحواس الخمس والتعلم الفائق مع المساعد الصوتي "تافي" (Voice: Tavi):**
   - قراءة صوتية نقية باستخدام أحدث نموذج صوتي **Gemini 3.8 Flash TTS** (`gemini-3.8-flash-tts`) بصوت **Tavi**.
   - **نطق النص الصافي فقط:** قراءة السؤال ومفتاح الحفظ مباشرة دون قراءة أي تعليمات أو أوامر توجيهية بصوت عالي.
   - **منع تداخل الأصوات (Anti-Overlap Engine):** إيقاف أي صوت أو طلب سابق فوراً عند النقر السريع على الأزرار لضمان عدم تداخل عبارات متعددة في آن واحد.
   - **اقتصار النطق على الأسئلة والمادة التعليمية:** إزالة نطق رسائل الانتظار أو الترحيب أو نصوص المؤقت واقتصار الصوت على الأسئلة وأسرار الحفظ.
   - نطق فصيح ومخارج حروف واضحة وسرعة أعلى قليلاً باللهجة السعودية النجدية الأصيلة والمحببة للطلاب.
   - وجود بديل محلي سريع ومطور عبر Web Speech API عند عدم توفر اتصال بالإنترنت.
   - أزرار استماع تفاعلية لكل سؤال وخيار وسر حفظ.

5. **إدارة الوقت الذكية ودعم المؤقت لمرحلة المذاكرة:**
   - مؤقت تنازلي نشط خلال **مرحلة المذاكرة (Study/Learn)** و **مرحلة الاختبار (Quiz)** على حد سواء.
   - **زر بدء الاختبار في جميع صفحات المذاكرة:** إمكانية الانتقال للاختبار فوراً في أي لحظة دون الحاجة لإنهاء كامل بطاقات المذاكرة.
   - زر `+5 د` ذكي يتفعل تلقائياً في الدقيقة الأخيرة من الوقت.
   - نافذة تنبيه فورية عند انتهاء الوقت تتيح خيار تمديد 5 دقائق أو بدء الاختبار/عرض النتيجة.

6. **منتقيان منفصلان للنماذج (Brain & TTS) مع فحص الاتصال:**
   - **منتقي نموذج العقل وتوليد الأسئلة:** لاختيار نماذج Flash و Pro (`gemini-3.8-flash`, `gemini-3.8-pro`, إلخ).
   - **منتقي نموذج الصوت والنطق:** لاختيار نماذج TTS الصوتية (`gemini-3.8-flash-tts`, `gemini-3.8-flash-lite-tts`, إلخ).
   - **زر فحص الاتصال بالنماذج (Connection Test):** اختبار فوري للاتصال بنموذج العقل ونموذج الصوت مع قياس زمن الاستجابة (Latency بالملي ثانية) وإمكانية الاستماع لعينة صوتية حية من تافي.
   - **شريط وملصقات إعلان الأخطاء:** عرض تنبيهات وأخطاء الـ API والنماذج وملفات الرفع كملصقات مرئية واضحة ومباشرة.

7. **أزرار البدء من جديد ومراجعة الأخطاء فقط:**
   - زر **"البدء من جديد"** في مرحلتي الحفظ (Study) والاختبار (Quiz).
   - شاشة نتائج ذكية تتيح خيار **"مراجعة أخطائي فقط"** أو **"اختبار الأخطاء فقط"** مع خيار إعادة دراسة واختبار المادة كاملة.

8. **حماية البيانات ونافذة تأكيد رفع المادة:**
   - نافذة تحذيرية منبثقة عند النقر على "رفع مادة جديدة" لمنع فقدان الأسئلة والنتائج السابقة عن طريق الخطأ.

9. **دعم شامل للملفات والمواد:**
   - 📷 صور المستندات والملخصات (JPG, PNG, WebP) مع دعم كاميرا الهاتف مباشرة.
   - 📄 مستندات الـ PDF عبر القراءة المتعددة الوسائط المباشرة.
   - 📝 ملفات Word الحديثة (`.docx`) عبر معالجة Mammoth.js في المتصفح.
   - ⌨️ خيار إضافي لكتابة أو لصق نصوص المواد والأسئلة مباشرة دون الحاجة لملف.
   - ⚡ خيار لاختبار تجريبي فوري (Demo Mode) لتجربة التطبيق بضغطة زر.

10. **المحرك الصوتي التوليدي (Web Audio Synthesizer):**
   - 🎵 **موسيقى التركيز الذهني:** موجات ألفا ثنائية الأذنين (Binaural Beats بفارق 8Hz) مع ألحان تأملية عشوائية على سلم دو الكبير تُولد لحظياً بدون استهلاك أي ملفات صوتية خارجية.
   - 🔔 **مؤثرات صوتية:** نقرات، نغمة إجابة صحيحة، نغمة خطأ، ونغمة النصر عند إتمام التحدي.

## 🚀 طرق التشغيل السريع

### الطريقة الأولى: التشغيل المباشر (الأسهل بدون تثبيت أي شيء)
يمكنك فتح ملف `index.html` مباشرة بالنقر المزدوج عليه في أي متصفح حديث (Chrome, Edge, Safari, Firefox).

---

### الطريقة الثانية: عبر خادم محلي مدمج (Local Server)
يحتوي المشروع على خادم Node.js خفيف مدمج بدون أي dependencies إضافية:

```bash
# تشغيل الخادم وفتح المتصفح تلقائياً
npm start
```
أو:
```bash
node server.js
```
سيفتح التطبيق على الرابط: `http://localhost:3000`

---

## 🔑 إعداد مفتاح Google Gemini API

1. احصل على مفتاح مجاني من [Google AI Studio](https://aistudio.google.com/).
2. عند فتح التطبيق، اضغط على أيقونة الإعدادات ⚙️ في الشريط العلوي.
3. الصق مفتاحك، وسيتم حفظه محلياً في متصفحك (`localStorage`) دون إرساله إلى أي خادم خارجي.

## 🌐 النشر على الإنترنت (Deployment)

التطبيق عبارة عن **Single-Page Application** خفيف ولا يحتاج إلى backend خاص:
- **Cloudflare Pages / Vercel / Netlify:** اسحب وأفلت المجلد أو اربطه بـ GitHub لنشر التطبيق خلال ثوانٍ.
- **GitHub Pages:** فعّل GitHub Pages من إعدادات المستودع واختر المجلد الرئيسي.
